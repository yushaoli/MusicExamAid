一句话看懂 MusicExamAid 解决什么问题

传统考级报名依赖家长微信发文字/照片、老师手动汇总 Excel，经常出现身份证号被 Excel 变成科学计数法 (`4.401E+17`)、二寸证件照命名混乱、同一考生跨机构重复报名。 MusicExamAid 把「家长填报 → 企微通知老师 → 老师一键锁档 → 自动去重并打包 标准Excel+命名证件照ZIP」变成一条闭环流水线。

STEP 1 家长 (微信服务号/小程序)

📝 家长填报 + 传二寸照

在服务号菜单打开 H5 (`/app?tab=parent`) 或小程序填写考生档案、上传二寸照并提交报名。

STEP 2 系统 → 企业微信

🔔 企微实时推送给老师

状态变为 submitted，通过 wecom.xgar.com.cn 推送 Markdown 卡片到老师企业微信。

STEP 3 老师/教务 (工作台)

🔒 老师一键确认并锁档

老师核对曲目与级别，支持一键确认并锁定 (submitted → locked) 或退回家长修改。

STEP 4 教务管理员 (导出中心)

📦 自动去重 + 导出 ZIP 包

SuperBatch 自动去重，一键下载 bundle.zip（含官方25列报名表 CSV + 自动命名的二寸照文件夹）。

💰 一师一价 · 按考级级别 (1-10级) 差异化收费与返佣 + 累计提现闭环

由于不同级别 (1-10级) 的考级收费标准不同，且不同合作深度老师的报考协议收费价 (`exam_fee`) 与返佣标准 (`concession`) 均因人而异，系统内置了 teacher_grade_rate_cards (teacher_id, level) 二维价目引擎：家长在微信支付时自动按「所属老师 + 报考级别」计费；老师锁档时自动按该老师对应级别的协议返佣记入「待管理员核算 (`accrued`)」；管理员还可随时二次微调金额并确认入账 (`confirmed`)，供老师一键申请提现。

0. 配置「老师×级别」协议价与返佣 ──家长微信支付──▶ 1. 按老师专属级别价收款 (paid) + 锁档 (locked) ──自动累计──▶ 2. 待管理员核算 (accrued) ──管理员确认/微调──▶ 3. 可提现余额 (confirmed) ──老师申请提现──▶ 4. 提现打款结清 (paid_out)

🔄 官方考级办后台 (`https://kjzx002120.kj5.zgyyxykj.com/admins`) 登录自动化与双端合并原理

我们对官方后台 「江西小戈尔文化艺术有限公司考级办管理后台」 的底层页面与登录接口进行了逆向分析，发现其存在两条登录链路，其中「微信扫码登录接口 (`wxauth`)」完全绕过了旋转图片验证码 (`capt.zgyyxykj.com`)，最适合做自动化会话桥接与双端报名合并：

🔑 方式 A：官方微信扫码会话桥接 (零验证码 · 推荐) POST /official-sync/qr-session
1. 自动抓取官方登录二维码与 PHPSESSID
• 后端请求 GET https://kjzx002120.kj5.zgyyxykj.com/admins
• 自动提取 Cookie PHPSESSID、10位令牌 wxauth_token 与内嵌 Base64 二维码图片
2. 手机微信扫一下 → 自动接管后台 Cookie
• 后端轮询 POST /admins/index/get_wxauth_status?token=...
• 扫码确认 (scan_status == 4) 后自动调用 /admins/index/wxauth_confirm，无需识别任何旋转验证码即可获得完整后台会话 (`/admins/manage?is_agent=0`)！
🔐 方式 B：账密 + 旋转验证码辅助 (`SparkMD5`) 备用通道
为什么纯脚本账密登录会被拦？
• 官方账密登录 (`POST /admins/index/pwd_login`) 会先对密码做 SparkMD5.hash(pwd.replace(/！/g,'!'))，并强制弹出 capt.zgyyxykj.com/captcha/rotate（旋转图片角度验证码）。
解决方案：一次扫码/人工滑块，全天复用 PHPSESSID
• 在我方教务台内嵌扫码框（或 1 秒人工完成一次旋转验证码），ubtxiaomi 即可持续复用该 PHPSESSID 自动拉取官网报名列表与上传增量包。
⚖️ 双端报名自动合并对账引擎 POST /official-sync/consolidate
按 (考期 + 科目 + 姓名 + 证件号后4位) 自动归类 4 种状态：
• 🔵 仅官网直报 (official_only)： 自动补录进本地总库，并自动按该学生指导老师的「老师×级别」协议价累计老师返佣！
• 🟡 仅助手填报 (helper_only)： 一键筛选出来导出 25 列标准包上传至官网。

• 🔴 级别冲突 (conflict_grade)： 如官网报 6 级、助手报 5 级，高亮拦截提醒教务核实。
